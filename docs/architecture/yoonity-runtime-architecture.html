페이지 응답

방문자 → Vercel Edge/CDN → Next.js App Router → 페이지 엔트리 → UI·도메인 모듈 → 렌더링 응답. 대부분의 화면 구성은 저장소의 서버 컴포넌트와 데이터 모듈을 통해 결정됩니다.

신뢰 경계

경계별 책임

브라우저는 신뢰할 수 없는 클라이언트 영역입니다. Vercel 런타임은 서버 코드·환경변수·외부 API 호출을 보호하며, Google Sheets·GA4·검색 엔진은 별도 외부 서비스 경계입니다.

실행 근거

저장소 매핑

라우트는 src/app, 공통 화면은 src/components, 콘텐츠는 src/data, 통합 로직은 src/lib에 위치합니다. SEO 출력은 src/app/sitemap.ts·robots.ts·structured-data.ts가 담당합니다.
